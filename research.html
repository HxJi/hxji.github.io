Research

My research focuses on memory-centric computer systems, with an emphasis on CXL-based memory expansion, heterogeneous cooperative computing, near-data acceleration, and datacenter memory efficiency.

CXL Memory Systems and Disaggregated Memory

I study how emerging CXL devices reshape memory hierarchy design, resource management, and system software for modern datacenter platforms.

  • Re-architecting End-host Networking with CXL: Coherence, Memory, and Offloading. MICRO 2025.
  • Demystifying a CXL Type-2 Device: A Heterogeneous Cooperative Computing Perspective. MICRO 2024.
  • Demystifying CXL Memory with Genuine CXL-Ready Systems and Devices. MICRO 2023.
  • Characterizing CXL Memory Management in a Production Cluster Management Host Agent. HCDS 2026.

Near-Data Acceleration for System Services

I design systems that offload memory-intensive operating-system and runtime services to specialized devices, reducing CPU overhead and improving datacenter efficiency.

  • Para-ksm: Parallelized Memory Deduplication with Data Streaming Accelerator. USENIX ATC 2025.
  • Cooperative Memory Deduplication with Intel Data Streaming Accelerator. IEEE CAL 2025.
  • Hardware-accelerated Kernel-Space Memory Compression Using Intel QAT. IEEE CAL 2025.
  • STYX: Exploiting SmartNIC Capability to Reduce Datacenter Memory Tax. USENIX ATC 2023.

Memory, Storage, and Data-Intensive Computing

I am also interested in architecture and system techniques for data-intensive applications, including storage latency modeling, graph analytics, and memory reliability.

  • MAC: Metadata Acceleration for Sustainable Performance in Big-Data Systems with CXL DRAM. OSDI 2026.
  • Time Series Machine Learning Models for Precise SSD Access Latency Prediction. IEEE CAL 2025.
  • X-PPR: Post Package Repair for CXL Memory. IEEE CAL 2025.
  • Graphite: Optimizing Graph Neural Networks on CPUs through Cooperative Software-Hardware Techniques. ISCA 2022.
